For my capstone project I would like to develop an AI powered tool that automatically generates clear and meaningful Git commit messages from code changes. The problem I want to solve is that developers often write vague commit messages, making it harder to understand previous changes and maintain projects. I plan to use GPT-4o with LangChain and Pydantic to generate and validate Conventional Commit messages, building on what I learned in Week 6 about prompt engineering. I also want to compare different models such as GPT-4o and Claude to see which produces the most accurate results. This project will extend the prompt engineering, API integration and output validation techniques covered in the course.
