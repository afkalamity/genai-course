I built a multi-provider LLM pipeline that runs three tasks on GPT-4o and Claude with retry logic, latency and cost tracking, and a results table. I also ran a 20 question hallucination audit on GPT-4o about machine learning papers at temperature 0 and tested an “I don’t know” system prompt on its most confident wrong answers. Finally, I compared four prompting strategies (zero-shot, few-shot, chain-of-thought, structured output with a role) for generating test cases. What surprised me was how confident GPT-4o was.
